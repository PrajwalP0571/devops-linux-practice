Phase 1 — Core Shell Scripting

Section 1: Variables & Data Types

You've used variables already. Let me formalize everything properly.
bash# Basic variable assignment — NO spaces around =
NAME="Prajwal"
AGE=25
IS_DEVOPS=true

# Accessing variables — use $
echo $NAME
echo "My name is $NAME and I am $AGE years old"

# Curly braces — use when variable is next to text
echo "${NAME}_backup"       # Prajwal_backup
echo "$NAME_backup"         # empty — bash looks for variable NAME_backup

# Read-only variables — cannot be changed
readonly DB_HOST="prod-db.internal"
DB_HOST="something-else"    # throws error

# Unsetting variables
unset NAME
echo $NAME                  # empty now

Special built-in variables — memorize these:
bash$0      # name of the script itself
$1, $2  # first, second argument passed to script
$#      # total number of arguments passed
$@      # all arguments as separate strings
$?      # exit code of last command (0=success, non-zero=failure)
$$      # PID of current script
$USER   # current logged in user
$HOME   # home directory path
$PWD    # current directory

Practical example:
bash#!/bin/bash
echo "Script name: $0"
echo "First argument: $1"
echo "Total arguments: $#"
echo "All arguments: $@"
echo "Current user: $USER"
echo "Current directory: $PWD"

Run it as:
bash./script.sh dev 8080 nginx
# Script name: ./script.sh
# First argument: dev
# Total arguments: 3
# All arguments: dev 8080 nginx


Section 2: User Input & String Operations
bash# Taking input from user
read -p "Enter environment: " ENV
echo "Deploying to: $ENV"

# Silent input (for passwords)
read -sp "Enter password: " PASSWORD
echo ""    # new line after silent input

# Input with timeout
read -t 10 -p "Enter choice (10 sec timeout): " CHOICE

# String operations
NAME="devops-engineer"

echo ${#NAME}              # length of string = 15
echo ${NAME^^}             # uppercase = DEVOPS-ENGINEER
echo ${NAME,,}             # lowercase = devops-engineer
echo ${NAME^}              # capitalize first letter
echo ${NAME/devops/mlops}  # replace devops with mlops
echo ${NAME:0:6}           # substring, start=0, length=6 = devops


Section 3: Conditionals — if/elif/else
bash#!/bin/bash

# Basic if
if [ condition ]; then
    # commands
fi

# if-else
if [ condition ]; then
    # commands
else
    # commands
fi

# if-elif-else
if [ condition1 ]; then
    # commands
elif [ condition2 ]; then
    # commands
else
    # commands
fi
Comparison operators — two types:
bash# Numeric comparisons
-eq    # equal to
-ne    # not equal to
-gt    # greater than
-lt    # less than
-ge    # greater than or equal
-le    # less than or equal

# String comparisons
=      # equal
!=     # not equal
-z     # string is empty
-n     # string is not empty

# File checks
-f     # file exists
-d     # directory exists
-r     # file is readable
-w     # file is writable
-x     # file is executable
Real examples:
bash#!/bin/bash

# Numeric
RAM=$(free -m | grep Mem | awk '{print $7}')
if [ $RAM -lt 200 ]; then
    echo "WARNING: Low memory - ${RAM}MB available"
elif [ $RAM -lt 500 ]; then
    echo "CAUTION: Memory getting low - ${RAM}MB available"
else
    echo "OK: Memory is healthy - ${RAM}MB available"
fi

# String
ENV=$1
if [ -z "$ENV" ]; then
    echo "Error: No environment specified"
    exit 1
fi

if [ "$ENV" = "prod" ]; then
    echo "Deploying to PRODUCTION — extra caution"
elif [ "$ENV" = "dev" ]; then
    echo "Deploying to development"
else
    echo "Unknown environment: $ENV"
    exit 1
fi

# File check
CONFIG="/etc/nginx/nginx.conf"
if [ -f "$CONFIG" ]; then
    echo "Nginx config found"
else
    echo "Nginx config missing — aborting"
    exit 1
fi


Section 4: Loops
bash# for loop — iterate over list
for item in item1 item2 item3; do
    echo $item
done

# for loop — iterate over range
for i in {1..5}; do
    echo "Iteration: $i"
done

# for loop — C style
for ((i=0; i<5; i++)); do
    echo "Count: $i"
done

# while loop
COUNT=0
while [ $COUNT -lt 5 ]; do
    echo "Count: $COUNT"
    COUNT=$((COUNT + 1))
done

# until loop — runs until condition becomes true
COUNT=0
until [ $COUNT -eq 5 ]; do
    echo "Count: $COUNT"
    COUNT=$((COUNT + 1))
done

# Loop over files
for file in /var/log/*.log; do
    echo "Processing: $file"
done

# Loop over command output
for user in $(cat /etc/passwd | awk -F: '{print $1}'); do
    echo "User: $user"
done

# break and continue
for i in {1..10}; do
    if [ $i -eq 5 ]; then
        continue    # skip 5
    fi
    if [ $i -eq 8 ]; then
        break       # stop at 8
    fi
    echo $i
done
